# TrueWorth - Inflation & Purchasing Power Calculator

**TrueWorth** is a web application for calculating the historical purchasing power of money using authentic Consumer Price Index (CPI) datasets for:

- **ETB - Ethiopian Birr** (1965 - 2025)
- **USD - United States Dollar** (1960 - 2025)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Running Tests

Execute the automated calculation test suite:

```bash
npm test
```

## Production Build

```bash
npm run build
```

## Data Sources & Methodology

- **Ethiopia**: World Bank Open Data & IMF International Financial Statistics / Ethiopian Statistical Service (ESS). Base Index: 2010 = 100.
- **United States**: World Bank Open Data & U.S. Bureau of Labor Statistics (BLS) CPI-U. Base Index: 2010 = 100.
